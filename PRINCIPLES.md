# The principle behind the skills

**Bring help, not noise — and earn the reviewer's trust.** AI made a plausible
change nearly free to produce, which shifts the whole cost onto the maintainer:
reading, verifying, and disproving work they didn't ask for. So the bottleneck is no
longer *generating* a contribution — it's proving it is real, scoped, and worth a
scarce reviewer's time. Every skill in this repo exists to send one trust
signal that earns it; none ships without a receipt that it did.
